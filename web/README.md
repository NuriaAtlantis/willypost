# WillyPost · web

Interfaz React 19 + Vite. Desarrollo: `npm install && npm run dev` (proxy a `http://localhost:4747`). Producción: `npm run build` genera `web/dist` (se sube al repo; el servidor lo sirve).
Constantes editables: `src/lib/constants.js` (`DOCS_BASE`). Contrato de la API: `../SPEC.md`.
